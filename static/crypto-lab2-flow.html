crypto-lab2 — Trading System Flow

atlantide-crypto-lab · Hybrid Scoring + Candlestick Pattern Scalp · 15m timeframe · loop every 1s

Step-by-Step Execution Flow

PHASE 1 Data Collection (every 1s)

1
WebSocket stream pushes 15m candle closes
Binance WebSocket delivers real-time 15m and 5m candles for 20 active symbols (60 total streams). Each closed 15m candle is appended to candles[sym]["15m"]. Ticker prices, highs, lows, volumes updated in shared state.
→ Ticker prices, highs, lows, volumes updated in shared state
2
Market data bootstrap (on startup only)
On first launch, REST API fetches 100 historical 15m candles per symbol. Gives enough data for EMA(50) + ATR(14) + RSI(14) calculations immediately.
Impact: Without this, strategy cannot run until ~12 hours of candles accumulate naturally.

PHASE 2 Strategy Evaluation (every 1s, per symbol)

3
compute_indicators() — Technical Analysis
From 30 closed 15m candles, calculate: ATR(14) for SL distance, RSI(14) for overbought/oversold, MACD(12,26,9) histogram for momentum, EMA(9) and EMA(21) for crossovers, EMA(20) for trend direction, EMA(50) for longer-term trend filter. Volume SMA(20) for volume spike detection. Volatility classification (low/normal/high) via ATR percentile over 50 periods.
→ indicators[sym] dict populated for display and downstream scoring
4
Candlestick Pattern Detection
Scan last 3 closed candles for: Hammer (long lower wick ≥ 1.5×body, tiny upper wick → LONG), Shooting Star (long upper wick ≥ 1.5×body, tiny lower wick → SHORT), Engulfing (current body fully engulfs previous body ×1.3 → direction of engulf), Doji (body <10% of range → skip pattern). Wick ratio tunable by self-learning (1.2–4.0).
Impact: Doji-cancelled candles excluded from pattern scoring. First detected pattern wins (priority: Hammer → Star, then Engulfing).
5
score_entry() — Multi-Signal Aggregation
Sum weighted scores from ALL active signal types into a total score (−8.0 to +8.0 range):
Hammer: +2.5 · Shooting Star: −2.5 · Engulfing: ±2.0 · EMA Cross (fresh): ±2.0 · EMA Position (no cross): ±1.0 · RSI Bounce: ±1.5 (scaled ×1.0–1.3 by depth) · MACD Histogram: ±1.0 (scaled ×0.5–1.5 by magnitude) · Volume Spike: ±0.5 (directionless, amplifies existing bias)
Impact: Volume signal signs itself based on total score (directionless → takes aggregate direction). EMA Position fires when no fresh EMA cross but EMA9 > EMA21 (or vice versa).
6
Candle Pattern Dominance Check — NOW BEFORE threshold
If the strongest signal is a candle pattern (Hammer/Star/Engulfing) but total score points the OPPOSITE direction → total score penalized by 70% (×0.3). This prevents conflicting signal pollution — e.g. a Hammer (+2.5) accompanied by conflicting negative signals (−3.0 total) gets crushed to −0.9.
Impact: MOVED BEFORE entry threshold check in this update. Previously it was after — now the penalty is applied before the threshold gate. A candle pattern's direction must reinforce the aggregate, not fight it.
7
Entry Threshold Check
If abs(total_score) >= entry_threshold (tunable 2.0–6.0, default 3.5) → signal passes to downstream filters. Otherwise → signal discarded.
Impact: Raising threshold = fewer trades with higher conviction. Lowering = more trades with more noise. Self-learning tunes this after every review cycle.
8
Regime Direction Filter — MOVED AFTER threshold
Downtrend + normal volatility → ONLY SHORT passes (returns None for LONG). Uptrend + normal volatility → ONLY LONG passes. Ranging or high/low volatility → both directions allowed. This is a FULL BLOCK (returns None), not a penalty.
Impact: New position in this update. Previously there was no regime direction filter. Now it sits AFTER the threshold check — only signals that already meet the score threshold face this direction constraint. In a strong downtrend, bullish signals are BLOCKED entirely.
9
TP/SL Calculation
SL: entry ± 1.5 × ATR(14) on 15m timeframe. Clamped to candle pattern range so SL cannot be placed absurdly far. TP: entry ± (SL_distance × RR_RATIO) where RR_RATIO = 2.0. RR ratio is now FIXED at 2.0 — no longer tunable by self-learning (was previously hot-reloadable via get_effective_param("rr_ratio")).
Impact: RR ratio removed from self-learning tunables. Previously had range 1.5–3.5. Now permanently fixed at 1:2. SL widened from 1.0× to 1.5× ATR to reduce false stop-outs on volatile 15m candles.
→ signal_state[sym] set: signal=LONG/SHORT, tp, sl, score, entry_type, trend, vol_label
10
Anti-Trend Filter (EMA50 slope ~2h) — NEW
New filter: if EMA50 slope over 8 periods (~2 hours) is bearish but signal is LONG → score halved (×0.5). If EMA50 is bullish but signal is SHORT → score halved. Requires 58+ data points to activate. This is a PENALTY, not a full block.
Impact: NEW in this update. Medium-term trend override using EMA50. Prevents trading against the dominant 2h direction. Unlike the Regime Direction Filter (which blocks entirely), this only PENALIZES (×0.5). Sits AFTER TP/SL calculation.

PHASE 3 Risk Filters & Execution (every 1s, per symbol)

11
Cooldown Check
If time since last trade close on this symbol < 15 minutes → skip. Prevents rapid re-entry after a loss.
Impact: After a losing trade, system waits 15 min before considering the same symbol.
12
Consecutive SL Pause
If symbol hit 5 consecutive stop losses → pause for 1 hour. Counter resets on any TP or TRAILING close.
Impact: Per-symbol circuit breaker. Stops the system from bleeding on a particular asset. Counter tracked in consecutive_sl_losses[sym].
13
Open Positions Loss Filter
If ≥50% of ALL open positions across ALL symbols have negative unrealized PnL → skip opening new trades entirely this tick. Requires at least 2 open trades to activate.
Impact: System-wide guard. Prevents stacking losses when most open trades are underwater.
14
Global 5-Loss Suspension ← FINGERPRINT GUARD
If the last 5 closed trades across ALL symbols are ALL losses → suspend all new entries for 2 hours. FINGERPRINT GUARD: Records suspension_fingerprint = len(closed_trades) at trigger time. Uses strict > comparison — same set of trades can never trigger a suspension twice. Existing open positions continue resolving during freeze.
Impact: BEFORE FIX: After 2h expiry, same trades still present → immediate re-trigger → permanent freeze. AFTER FIX: Fingerprint uses strict > comparison plus separate guard expiry clear.

PHASE 4 Trade Opening & Monitoring

15
Position Sizing
Base risk = 10% of per-symbol capital. Adjusted by confidence multiplier (score 3.5–5.0 → 0.75×, 5.0–6.5 → 1.0×, 6.5+ → 1.5×). Volatility multiplier (high vol → 0.5×, low vol → 1.2×). Final notional = risk_amount / SL_distance_pct. Margin capped at 2× available balance. Leverage = 5×. Max 1 open trade per symbol.
Impact: Only 1 open trade per symbol. In high volatility, position size halves.
16
Open Trade — Record to State + DB
Trade dict appended to open_trades[sym]. Includes: id, entry price, direction, TP, SL, notional, margin, entry_fee, risk_amount, confidence_mult. last_entry_signal set to prevent re-entry on same signal. State saved to SQLite. Conditions snapshot captured.
→ state saved to atlantide.db · SSE broadcast to dashboard · conditions snapshot
17
Monitor Open Trades (every 1s)
For each open trade: update unrealized PnL from current price. Check TP hit → close. Check SL hit → close. Check trailing stop: activates at 50% of TP distance, trails at 30% behind price extreme, capped at breakeven — never lets trailing SL go below entry for LONG or above entry for SHORT.
Impact: Trailing stop capped at breakeven — guarantees trailing stops never turn a winning trade into a loss. Profitability check ensures TRAILING label only on genuinely profitable closes (not gap-through losses).
18
Trade Close — PnL & Capital Update
Gross PnL = (exit−entry)/entry × direction × notional. Deduct entry_fee (0.05%) + exit_fee (0.05%). Update per-symbol capital: balance, total PnL, win/loss counters, peak, max drawdown. Consecutive SL counter incremented on SL closes, reset on TP/TRAILING. Trade scored + conditions snapshot captured.
→ closed_trades[] append · SQLite INSERT · SSE broadcast · Self-learning trigger · Conditions snapshot

PHASE 5 Self-Learning (reviews every 10 new trades / 60s loop)

19
Compute Performance Metrics
Sharpe ratio, profit factor (gross_win/gross_loss), win rate, avg win/loss, expectancy, max drawdown. Per-entry-type breakdown: count, wins, PnL, win rate for each of HAMMER, SHOOTING_STAR, ENGULFING, EMA_CROSS, RSI_BOUNCE, MOMENTUM. Goal progress: Sharpe (target 1.5), Win Rate (target 40%), Monthly Return (target 10%).
20
Diagnose & Tune One Parameter
IF any entry type has <25% win rate after 5+ trades → raise entry_threshold. ELIF win rate <28% + PF<1.0 → raise entry_threshold. ELIF win rate ≥40% but PF<1.5 → increase risk_pct. ELIF win rate <32% + PF<1.0 → raise wick_ratio. ELSE cycle to next param. Change by ±10% per iteration. If param stuck at bound → try next param.
Impact: Only ONE parameter changes per review. RR ratio REMOVED from tunable params — now FIXED at 2.0. Remaining params: entry_threshold (2.0–6.0), wick_ratio (1.2–4.0), risk_pct (5%–20%). Hot-reloadable via active_params[].
21
Forced Review on 5 Consecutive Losses
On every trade close, checks if the last 5 closed trades across ALL symbols are ALL losses. If so, triggers immediate forced review cycle (bypasses the 10-trade interval). Throttled: max once per 10 minutes.
Impact: Catches bleeding streaks in real-time rather than waiting for the next 10-trade review. 10-minute throttle prevents churn.

Signal Types & Weights

  • Hammer (bullish) +2.5
  • Shooting Star (bearish) −2.5
  • Engulfing ±2.0
  • EMA 9/21 Cross (fresh) ±2.0
  • EMA Position (no cross) ±1.0
  • RSI Bounce ±1.5 (scaled ×1.0–1.3)
  • MACD Histogram ±1.0 (scaled ×0.5–1.5)
  • Volume Spike ±0.5 (directionless)

Circuit Breakers

  • 15-min cooldown per symbol
  • 5× consecutive SL → 1h pause per symbol
  • ≥50% open positions underwater → skip new
  • 5 straight losses → 2h freeze (fingerprint guard)
  • Candle dominance check (×0.3 penalty, BEFORE threshold)
  • Regime direction filter (BLOCK counter-trend, AFTER threshold)
  • Anti-trend EMA50 (×0.5 penalty, AFTER TP/SL)
  • Trailing stop capped at breakeven

Self-Learning

  • Reviews every 10 closed trades (or 60s loop)
  • Tunable: entry_threshold 2.0–6.0
  • Tunable: wick_ratio 1.2–4.0
  • Tunable: risk_pct 5%–20%
  • RR ratio FIXED at 2.0 (removed from tunables)
  • One param change per cycle
  • Bound fallback: tries next param if stuck
  • 5-loss forced review (10min throttle)
  • Per-entry-type performance tracking
